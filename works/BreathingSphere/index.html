Tech Stack

C++ openFrameworks ofxPhyllotaxis ofxRollingCam

植物の模様がつくられるパターン（フィロタクシス）を利用できるアドオンを使用しました。
最初は ofDrawCircle() を使い2次元で制作していたのですが、ofDrawSphere() に切り替え ofxRollingCam を利用することで、3次元化しました。
三角関数の周期的な動きで動いていますが、各変数ごとに周期を変えることで、少しずつ模様が変化していくようにしました。

Description

私はいつも AI に助けてもらいながら、コーディングをしています。今まではメインで使用している AI が Gemini だったので、 Gemini CLI を使っていましたが、的外れな返答をしてきたり十分に親切ではなかったりしたのが不満でした。
そのため Claude の Pro プランに登録し、この作品も Claude Code に助けてもらいながら制作しました。
