Tech Stack

C++ openFrameworks ofxMidi LaunchPad Mini MK3

ハードウェアとの連携がしてみたい、けれど Arduino や M5Stack をいきなり買うのは怖いので、所有していた LaunchPad を使いました。
LaunchPad からの MIDI 入力に対して、ウィンドウの対応する場所に ofCurveVertex() で曲線を引き、また LaunchPad に MIDI 出力を返すことで LaunchPad を光らせています。
LaunchPad には Programmer Mode というのがあり、除算や剰余でうまく座標を計算できるように最初から MIDI マッピングされていました。そのあたりのプログラムを組むのが楽しかったです。

Description

PC のキーボードやトラックパッドでも十分インタラクティブな設計はできるけれど、LaunchPad を始めとしたハードウェアがさらにその体験を高めてくれるような気がします。Arduino や M5Stack はさらにその力を秘めていると思いました。

Additional Notes

ユーザーガイドは Programmer Mode の MIDI マッピングの確認などに使いました。 12歳ぐらいの時に少しだけ Arduino を触ったけれど、何も覚えてません。
