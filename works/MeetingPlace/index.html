Tech Stack

Cavalry

以前カネコアヤノの明け方という曲でつくった動画が気に入っていて、また少し似たものをと思い、つくり始めました。
Cavalry の色々なエフェクトや機能を試しながら、前回よりも特徴的になるよう心がけました。

Description

文字を使って歌詞をシンプルに表現することを目標にしました。熱を赤色の図形で表現したり、手や足の写真を使ったり、抽象と具象を行き来するような映像です。個人的には記憶と記録が熱に浮かされるところが好きです。

Additional Notes

螺旋の映像も Cavalry で作成したのですが、後々 openFrameworks を使って再構築しました（動画）。Cavalry を下書き、oF を清書のように使うのはやりやすい気がします。
