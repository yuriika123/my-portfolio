Tech Stack

C++ openFrameworks (for iOS) ofxSelfOrganizingMap

oF 向けのアドオンを漁っていて見つけた上記のアドオンを使用し、カメラの入力からピックアップした色を元に模様ができていくアプリを制作しました。
初めは iPhone と Mac の連携カメラを使用し macOS 用のアプリとして制作しました。その後で、カメラが付いていて持ち運びなどにも適している iPhone 向けに iOS アプリとして再設計しました。oF を使用してつくった iOS アプリとしては初めてです。

Description

カメラが見ている視覚をもとに連続的に色が変化していく様を季節に見立てて、“Seasonal Colors” というタイトルをつけました。
今までは macOS 用のアプリしかつくってこなかったので、カメラやセンサーなどリアルタイムの入力を活かしたアプリはあまりありませんでした。iPhone に付いているカメラという名の目を利用することで、現実世界とコンピュータの中の世界が繋がったような感覚になりました。
